## Prerequisites

- <<prereq.node>> Node.js 20+
- <<prereq.go>> Go 1.24+
- <<prereq.git>> git
- <<prereq.gcloud>> gcloud CLI (Google Cloud SDK)
- <<prereq.firebase>> Firebase CLI (`npm install -g firebase-tools`)
- <<prereq.glab>> GitLab CLI (optional — only if you'll deploy via GitLab CI)

## Cloud Authentication

Required before `setup-gcp.sh` can provision anything.

- <<cloud.gcp_auth>> `gcloud` authenticated (`gcloud auth print-access-token` works)
- <<cloud.firebase_auth>> `firebase` CLI authenticated (`firebase projects:list` works)
- <<cloud.gitlab_auth>> `glab` authenticated (optional — `glab auth status` shows logged in)

## Bootstrap

These steps run once after forking, before any normal dev work.

- <<bootstrap.config_env>> `bootstrap/config.env` exists and required keys are filled in
- <<bootstrap.firebase_dev>> `FIREBASE_*_DEV` keys populated (auto-pulled by `setup-gcp.sh dev`)
- <<bootstrap.firebase_prod>> `FIREBASE_*_PROD` keys populated (auto-pulled by `setup-gcp.sh prod`)
- <<bootstrap.init_run>> `bootstrap/init.sh` has been run (no `{{ KEY }}` placeholders remain in source)
- <<bootstrap.frontend_env>> `frontend/.env.local` exists with non-empty Firebase API key

## Dependencies & Build

- <<deps.npm>> Frontend dependencies installed (`frontend/node_modules` exists)
- <<deps.go_build>> Backend builds (`cd backend && go build ./...`)
- <<deps.go_test>> Backend unit tests pass (`cd backend && go test -short ./...`)
- <<deps.fe_test>> Frontend tests pass (`cd frontend && npx vitest run`)

## What's next

If everything above is checked, you can start the dev loop:

```bash
# Terminal 1: Firebase emulators
firebase emulators:start --only firestore,auth,pubsub --config firebase.test.json

# Terminal 2: backend
cd backend && make run

# Terminal 3: frontend
cd frontend && npm run dev
```

If something is still unchecked, the `/onboard` summary above told you the
exact command to run. Re-run `/onboard` after each step to refresh this file.
