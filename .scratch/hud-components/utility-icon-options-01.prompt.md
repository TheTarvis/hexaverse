## Prompt

Use case: ui-mockup.
Create a polished high-resolution comparison image for utility icon art direction in the Hexaverse space-game HUD. Input is the accepted coded typography and shell reference, not an edit target. Four equally sized panels in a generous 2x2 grid, quiet dark navy background. Use the same shell in all panels. Tab text "UTILITY ICONS". No glow on icon artwork; accepted corner-light accents may glow. Plain flat white/ice-cyan icons.
Explore FOUR consistent icon families, not game-object art or button backgrounds.
Outside each panel label:
"A · LIGHT OUTLINE"
"B · MEDIUM OUTLINE"
"C · TWO TONE"
"D · SOLID"
Each panel contains the same six icons in the same column order, large and clearly legible:
1 BACK: simple left arrow with horizontal shaft.
2 SEARCH: magnifying glass, circular lens and diagonal handle.
3 FILTER: familiar funnel.
4 EXPAND: down-pointing chevron.
5 INFO: circle containing lowercase i.
6 CLOSE: diagonal X.
Use standard recognizable geometric forms, no fanciful glyphs, no decorative microdetail.
Under the large icon row, show these six exact labels "BACK", "SEARCH", "FILTER", "EXPAND", "INFO", "CLOSE", in small cyan uppercase monospaced lettering matching accepted label typography.
Below a quiet thin divider, a small label "COMPACT SIZE", then repeat the same six glyphs at a smaller realistic UI scale, around 18–20px equivalent. Make clear that these are the same glyph family in both sizes. Show icon shapes without boxes, pills, button borders or background tiles. The canvas may enlarge the whole UI proportionally for readability but preserve the size ratio.

A LIGHT OUTLINE: fine uniform strokes, about 1.25px at 20px UI size, round linecaps, simple geometric icon outlines; clean airy low weight.
B MEDIUM OUTLINE: about 1.75px at 20px UI size, consistent round caps and joins; more substantial but crisp, familiar open shapes. Same essential geometry as A.
C TWO TONE: pale cyan foreground outlines and restrained blue-gray secondary flat fill inside bounded shapes, no gradients/glow. Funnel bowl soft fill, magnifier lens soft fill, info circle soft fill; arrows and X use clear pale strokes. Harmonious two-tone icon family.
D SOLID: compact filled/silhouette shapes and intentional negative spaces; magnifier still has an OPEN circular lens, info is filled circle with cutout i, funnel filled, chevron and arrow use thicker flat silhouettes. Crisp regular weight, not chunky cartoon icons.

Utility semantics, labels and size are identical across panels; only icon drawing treatment changes. Typography stays the accepted flat near-white/cyan styling. Do not draw fleet/planet/station objects, gameplay status indicators, extra controls or animations. The existing shell close X stays identical across panels; sample CLOSE glyphs are for comparison only. No watermark. Every panel fully visible and aligned.
