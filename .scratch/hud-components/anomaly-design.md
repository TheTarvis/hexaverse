# Anomaly visual design

Status: brief settled; awaiting shared-understanding confirmation before concept generation.

## Settled brief

- Purpose: a visual identifier that encourages the player to investigate and
  Analyze. Travis describes anomalies broadly: strange physics, an unanalyzed
  ship, an ancient artifact, or other discoveries.
- Destination: both the live scene and a static 32px HUD portrait.
- Scope: visual design only. This session does not establish harvesting,
  danger, traversal, discovery rules or other gameplay mechanics.
- Future: the initial artwork is revisable; anomalies may eventually have
  multiple visuals as their meanings expand.
- Meaning: the identifier represents the mystery before Analyze. Recognizable
  art replaces it once analysis establishes the underlying object's nature.
- Relationship to existing art: refine the accepted diffuse unanalyzed return
  toward one shared mystery identifier. Keep the accepted return as the baseline;
  replace it only if Travis prefers and accepts the new concept.
- First comparison: A diffuse knot (concentrated irregular glow with soft
  edges), B broken halo (incomplete luminous arcs around an obscured center),
  C offset echoes (overlapping translucent shapes with slight misalignment).
- First-round palette: restrained pale violet and white, with comparable space
  backgrounds. Conceal the underlying object; avoid literal ships, artifacts
  and portal openings.
- These are abstract identifier treatments, not depictions of the underlying
  object's physical nature. No manufactured style profile is assigned.
