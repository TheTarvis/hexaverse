## Prompt

Use case: ui-mockup.
Refine option C STATIC THUMBNAILS from reference image 1. The user is leaning toward small static model portraits rather than category symbols. Reference image 2 is the accepted COMPACT coded HUD card typography; preserve that flat extended geometric name type, cyan monospaced labels, regular-weight figures, navy surface, clipped medium angular gunmetal frame and subtle cyan corner lights.
Make ONE large, highly readable comparison sheet, four same-width cards in a 2x2 grid, fully visible, on quiet navy. The ONLY major variable is thumbnail size and its resulting row height. Exterior labels precisely:
"C1 · 24px"
"C2 · 32px"
"C3 · 40px"
"C4 · 48px"
These are nominal actual UI sizes, render the entire sheet at a consistent enlarged scale to make the smallest option readable. Maintain relative thumbnail sizes accurately: 24 : 32 : 40 : 48 = 1 : 1.33 : 1.67 : 2. All four cards must have identical width and frame thickness. Centered top border tab says "OBJECT THUMBNAILS". Match accepted compact typography, do not use generic large sans names.

Each card repeats the same four rows in same order:
Row 1 name "Peregrine" with small secondary "Fleet · 3 ships"
Row 2 name "Aurelia Station" with small secondary "Station · Orbital"
Row 3 name "Rocky world" with small secondary "Surface body"
Row 4 name "Resource site" with small secondary "Asteroid field"
Each row's thumbnail sits LEFT of its text with a consistent modest gap (8px nominal), name above secondary line. Quiet hairline separator between rows. No gameplay status colors, badges, extra columns, buttons, icons or selection markers. These are image-size samples, not a final fleet list layout.
Thumbnail artwork: STATIC cutout mini renders, identical exact artwork across all four sizes. Fleet: industrial gray utility spacecraft with green accent strips, a compact broad wedge/catamaran silhouette matching reference 1's C thumbnail. Station: gray circular ring orbital station with a central tower, matching reference 1 C. Rocky world: mottled gray-brown sphere with a bright lit face and visible terminator; resource site: cluster of three to five irregular gray asteroids. Tiny images should have crisp silhouettes, simple directional lighting and a transparent/background-matching surround. Same camera angle, lighting, color and subject identity in every card. No portrait frame, glow ring, crest, drop-shadow tile or circular badge behind thumbnails.
Keep content compact and readable: names approx 16px nominal geometric font, secondary sans approx 12–13px; consistent text sizes across all variants; font stays flat near-white and blue-gray, no gradient or glow. Rows adapt only enough to fit their thumbnail while retaining compact 8px nominal vertical padding. Card height may fit the content rather than adding artificial empty space. Emphasize realistic small UI usage, no oversized showcase portraits masquerading as tiny icons.
No additional explanatory text, no animation controls, no rotating arrows, no pixel dimensions labels inside cards, no performance claims, no watermark. This is a visual reference only; final assets would be rendered from existing game models.
