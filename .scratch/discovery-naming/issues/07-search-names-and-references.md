# 07: Search places by current name or permanent reference

**What to build:** Players can find destinations through existing object-search surfaces using either the current public name or a permanent catalogue reference, with enough context to distinguish repeated body names across systems.

**Blocked by:** 05: Preview and confirm a permanent celestial name remotely.

**Status:** ready-for-agent

- [ ] Existing available object-search surfaces accept current display names and permanent catalogue references using authoritative server names and stable identity-based selection/navigation.
- [ ] A renamed destination remains findable by its unchanged catalogue reference. Search results use the new public name consistently with map and interior projections; no generated-name alias search is required.
- [ ] Body results include their enclosing star and catalogue reference so identical body names in different systems remain distinguishable. A star rename updates that enclosing-star context consistently.
- [ ] Search respects existing read visibility and corporation filtering and does not broaden celestial disclosure or expose foreign fleets through historical claim/discovery records.
- [ ] Existing backend and frontend seams verify reference lookup after naming, shared results across authorized viewers, repeated body names in different systems, and selection/navigation to the correct immutable target.
