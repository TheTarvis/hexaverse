# Historical gameplay design

These notes preserve design decisions and experiments from before the Matt
Pocock skills migration. Chain checklists, team commands and archive gates in
older documents describe the retired workflow. Code and tests define current
behavior; new work uses the skills and `.scratch/` tracker described in
`docs/agents/issue-tracker.md`. Consult these notes for design context without
treating unfinished checklist entries as an active backlog.

The migration retired the old OpenSpec and handoff trees; their records remain
available in Git at the pre-migration commit `a9eeaf0`.
