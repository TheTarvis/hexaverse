# Marketing

Where we track how Hexaverse gets talked about in public — what got posted,
what landed, and what to do more of.

Structured to match Flywheel's `docs/marketing/` so the habits carry over.

## Contents

- `social/` — per-platform activity logs, drafts, and screenshots. See
  `social/CLAUDE.md` for the convention. Only `x/` is live so far.

Add sibling directories (`videos/`, `content-ideas/`, `brand/`) as they earn
their keep — don't pre-create empty scaffolding.
