## Decisions
Use a shared external selection store backed by sessionStorage, keyed by corporation from the owned fleet read. Resolve ids only against the current owned fleet list; deleted ids fall back to a local/preferred fleet then the first owned fleet, including transit. Storage denial must not interrupt play. Selection writes happen before route navigation.
Reuse VitalsStrip in galaxy and system. A shared FleetLocationPanel presents location, route, ETA/progress, focus and destination navigation. Galaxy focus targets the destination during transit (not a fabricated fleet coordinate); ordinary fleets open their current system directly with a close camera centered on the selected fleet. A transit record remains transit after ETA until a successful fleet read clears it. Poll galaxy fleets at the existing board cadence so arrival updates even without an SSE event. Existing system departure navigation stays intact.
Only the current system's non-transit selected fleet gets local course/mining controls. Do not resolve a remote fleet's body ids against the current interior. No new gameplay endpoints or fabricated transit positions.

System entry focuses the selected local fleet once. Explicit fleet-focus requests carry a sequence so selecting the same fleet again recenters it; ordinary refetches never reset the camera. Fleet focus uses a clamped distance of 0.3 times the system extent.

Fleet focus stores a follow id in camera state. The shared transform loop resolves its pivot against each live scene, without per-frame React state updates. Initial framing looks inward along the fleet’s radial direction with a small elevation. Pan and other-object focus clear the id; orbit and zoom preserve it. Input operations start from the published live camera.

Contextual follow derives a parked anchor from the served body hierarchy, stopping before the star. Scene metadata includes its live position and an orbital envelope covering nested orbit radii and the fleet park offset. Travel keeps the fleet pivot. The transform loop blends pivot changes for 650ms in wall time, skips blending for reduced motion, and leaves yaw/pitch unchanged. Docked framing fits the envelope to the viewport; missing hierarchy falls back to the fleet.

The live and storyboard views share SystemObjectIndex and its stylesheet. Live objects derive solely from the interior read and owned fleet telemetry; no new query or order endpoint is introduced. Object expansion retains search, external canvas selection updates an open detail panel, and Focus uses the existing body-focus request. Plot closes the index to reveal the existing authoritative course panel. The command column stays mounted while hidden to preserve action state. The tutorial target control opens discovery; mobile details replace the list.
