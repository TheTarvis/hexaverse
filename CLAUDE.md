# CLAUDE.md

## Project Reset

Hexaverse is being rebuilt from the ground up on a new foundation. The
previous implementation (Next.js client, Firebase functions, Go websocket
server) has been retired.

This project is now the first fork of the **Volt** platform. The next commit
introduces the Volt foundation as it exists today; all future work builds
on it.

The old implementation is preserved in:
- The "Checkpoint" commit immediately before this one (full snapshot)
- The `archive/pre-volt-reset` branch (original client history)
